# 工控机 EGO 2D 控制器

以 JackJu-HIT/Ego-Planner-2D-ROS2 的 master 核心实现 Nav2 Controller 插件。固定版本见 UPSTREAM.md。
局部 B-spline 优化来自上游；本包实现非完整约束差速跟踪、真实 footprint 碰撞检查、速度/加速度限制、过期数据与规划超时拒绝。

## 验证与边界

编译与隔离单元测试不启动真实导航或串口。实车运行、CPU 负载下规划预算、走廊与动态障碍、目标取消/定位丢失停车需要现场验收。EGO 绕障可能偏离清扫线；本版本不重新计算绕障后漏扫面积。

替换局部控制器不解除导航就绪、定位、地图或底盘自主状态的要求，也不迁移工控机只读串口到运动控制。若原流程停在“等待导航就绪”，仍需查看具体失败项。

## 2026-10-26 绕障后回归原路线

### 距离与优化目标

- 驱动轴保守膨胀仍为 `0.60 + 0.25 + resolution`，当前 0.05 m 栅格对应 0.90 m。安装偏移补偿没有删除。

- 新增回归原路线的平方误差代价、控制多边形边长平方代价。原路线单独传入，旧绕障轨迹只作普通续规划的初值。回归目标只从已膨胀地图中的安全路线段选取，不跨障碍吸引；一次求解期间固定目标和可见性，保证 L-BFGS 目标连续。

### 回归点与切换条件

1. 按当前执行路线的顺序前进，在第一个距离局部极小值后限制搜索，避免跳到空间上更近的后续清扫线。
2. 从前方依次选择候选回归点；检查连接线、候选之后至少 0.50 m 路线，以及连接与路线方向。候选只是求解初值，最终曲线仍必须通过完整碰撞检查。
3. 偏离原线至少 0.20 m，或旧轨迹使用已满 3 s 时，评估提前回归；即使未到旧轨迹末端也可触发。
4. 每 0.5 s 检查一次；连续两次发现同一附近的安全回归点后才尝试规划。时间倒退或换任务时清除确认状态。
5. 比较新旧轨迹前方最多 1.5 m 的平均路线偏差，新轨迹至少改善 0.05 m 才替换。没有安全连接、改善不明显、超时或优化失败时，不强制换路；旧轨迹仍需通过当前地图碰撞检查，否则拒绝发出命令。
